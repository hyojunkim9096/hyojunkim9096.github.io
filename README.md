# WInO 포트폴리오

- `index.html` 포트폴리오 한 페이지. 글꼴(Pretendard · Outfit)만 바깥에서 불러오고, 못 불러오면 기본 글꼴로 보여요. 더푼다 그림 네 장은 `img/` 에 있고 나머지 그림은 이 파일 안에 있어요.
- `og.png` 카카오톡 같은 곳에 주소를 붙였을 때 보이는 그림(1200×630).
- `p/index.html` QR 이 가리키는 고정 주소. 포트폴리오로 넘겨요.
- `.nojekyll` GitHub Pages 가 파일을 그대로 내보내게 해요.

검색에 나오게 하려면 `index.html` 맨 위의 `noindex` 한 줄을 지워요.
